# GitHub Upload Guide

## Recommended repository

**Name**

`aegisrag-ai-governance-copilot`

**Description**

`Evidence-grounded GenAI governance copilot using hybrid RAG, EU AI Act and NIST AI RMF, with risk screening, citations, FastAPI, Streamlit and evaluation.`

**Visibility**

Public

Do not initialise the GitHub repository with a README, `.gitignore`, or licence because they are already included.

## Browser upload

1. Extract the downloaded ZIP.
2. Open the extracted `aegisrag-ai-governance-copilot` folder.
3. On the empty GitHub repository page, click **uploading an existing file**.
4. Select all contents inside the extracted folder and drag them into GitHub.
5. Wait until every file finishes uploading.
6. Use this commit message: `Add complete AegisRAG Generative AI governance project`
7. Commit directly to the `main` branch.

## Repository topics

`generative-ai`, `rag`, `llm`, `ai-governance`, `responsible-ai`, `eu-ai-act`, `nist-ai-rmf`, `fastapi`, `streamlit`, `watsonx`

## Final checks

- The repository root displays the project folders rather than one extra nested folder.
- The README renders the architecture diagram and evaluation image.
- GitHub Actions opens the CI workflow and shows a successful run.
- No `.env` file or API key is uploaded.
